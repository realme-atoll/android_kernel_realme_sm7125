# Unified Linux Kernel for Realme SM7125 (Atoll)

This repository contains the Linux 4.14 unified kernel source for Qualcomm Snapdragon 720G (SM7125 / Atoll) Realme devices running AOSP / LineageOS-based custom ROMs.

## Supported Devices

- **Realme 6 Pro** (`RMX2061`)
- **Realme 7 Pro** (`RMX2170`)
- **Realme 8 Pro** (`RMX3081`)
